# 3D studio — page override

Keep focus on the architectural study rather than an over-dense dashboard. A dark canvas sets the scene; the model itself has neutral daylight and warm sunset appearances. Controls are a compact low-position HUD; selected state uses a clearly contrasting ivory fill. Four actions: Day, Sunset, Blueprint, Pause/Rotate; Reset View is separate. `aria-pressed` exposes state changes. Mobile controls show 4-column grouped actions with at least 44px tap height and an always visible fallback message if WebGL is unsupported.
